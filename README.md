# Topo25000

登山用の 1:25,000 地形図PDFと行動計画を、iPhone・PCのブラウザだけで作るPWAです。

## できること
- 地図タップ・地名検索・緯度経度で地点（登山口→分岐→山頂…）を追加
- 標高を国土地理院APIから取得し、各地点の到着・出発時刻を目安計算（手入力で上書き可）
- 日の出・日の入りと、日の入り前に終わるかの警告
- A4の縦横を自動選択（1枚に収まらない時は1 km重ねで複数ページ）
- 磁北線1 km（紙上40 mm）間隔、偏角は国土地理院2020.0年値の近似式
- 地点番号・地点名・時刻と行程表をPDFに記入（登山路は描かないので手書き用）
- 400 dpi出力（A3への141%拡大コピーでも約280 dpi）
- YAMAP・ヤマレコの似た行程の最新記録を探すリンク
- ホーム画面に追加するとアプリとして起動、計画は端末内に保存

## 使い方
1. GitHub Pages などHTTPSで公開したURLを開く
2. iPhoneは共有ボタン →「ホーム画面に追加」
3. 印刷は「実際のサイズ / 100%」

## 出典
- 背景地図：国土地理院「地理院タイル（標準地図）」
- 標高：国土地理院 標高API ／ 地名検索：国土地理院 地名検索API
